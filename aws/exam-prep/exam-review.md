## Exam Review & Tips


### Practice Makes Perfect

- If you’re new to AWS, practice the services covered in this guide before rushing to the exam
- The exam recommends one or more years of hands-on experience on AWS
- If you feel overwhelmed by the amount of knowledge, review the material one more time


### Proceed by Elimination

- Most questions are going to be scenario-based
- For all the questions, rule out answers that you know for sure are wrong
- For the remaining answers, understand which one makes the most sense
- There are very few trick questions – don’t over-think it
- If a solution seems feasible but highly complicated, it’s probably wrong


### Skim the AWS Whitepapers

Recommended whitepapers to review:

- Architecting for the Cloud: AWS Best Practices
- AWS Well-Architected Framework
- AWS Disaster Recovery (https://aws.amazon.com/disaster-recovery/)


### Read Each Service’s FAQ

- FAQ = Frequently Asked Questions
- Example: https://aws.amazon.com/vpc/faqs/
- FAQs cover a lot of the questions asked at the exam
- They help confirm your understanding of a service


### Get into the AWS Community

- Review questions asked by other people online
- Do practice tests
- Read forums and online blogs
- Attend local meetups and discuss with other AWS engineers
- Watch re:Invent videos on YouTube (AWS Conference)


### How the Exam Works

- Register online at https://www.aws.training/
- Fee for the exam is $150 USD
- Provide one identity document (ID, Passport)
- No notes, no pen, no speaking allowed
- 65 questions in 130 minutes
- Use the “Flag” feature to mark questions you want to re-visit
- To pass you need a score of at least 720 out of 1000
- You will know within 5 days if you passed / failed (most of the time less)
- If you fail, you can retake the exam 14 days later


### AWS Certification Paths

**Foundational:** Knowledge-based certification for foundational understanding of AWS Cloud. No prior experience needed.

**Associate:** Role-based certifications that showcase your knowledge and skills on AWS. Prior cloud and/or on-premises IT experience recommended.

**Professional:** Role-based certifications that validate advanced skills. 2 years of prior AWS Cloud experience recommended.

**Specialty:** Dive deeper into strategic areas. Refer to exam guides for recommended experience.

**Key certification paths:**

| Domain | Certifications |
| --- | --- |
| Architecture | Solutions Architect (Associate, Professional), Application Architect |
| Operations | Systems Administrator, Cloud Engineer |
| DevOps | Test Engineer, Cloud DevOps Engineer, DevSecOps Engineer |
| Security | Cloud Security Engineer, Cloud Security Architect |
| Development | Software Development Engineer |
| Networking | Network Engineer |
| Data Analytics | Cloud Data Engineer |
| AI/ML | Machine Learning Engineer, Prompt Engineer, ML Ops Engineer, Data Scientist |

Full path diagram: https://d1.awsstatic.com/training-and-certification/docs/AWS_certification_paths.pdf
