## Development 

1. Install minikube.
   + [Go for official docs](http://minikube.sigs.k8s.io/docs/start/?arch=%2Flinux%2Fx86-64%2Fstable%2Fbinary+download)
   + run given commands.
   + run `minikube start` to start
2. Install kubectl.
   + [Go for official docs](https://kubernetes.io/docs/tasks/tools/)
   + follow there.
