# Shell

The shell takes commands from the user (via keyboard or script) and passes them to the kernel for execution.


## 🔹 Types of Shells
- **Gnome** → GUI shell
- **KDE** → GUI shell 
- **sh** → Original Bourne shell  
- **bash** → Bourne Again Shell (most common)  
- **zsh** → Advanced with auto-completion  
- **csh / tcsh** → C-like syntax  
- **ksh** → Korn shell  

Check your current shell:
```bash
echo $SHELL
```

List installed shells:
```bash
cat /etc/shells
```

We can see our assigned shell in: 
```bash
cat /etc/passwd
```
vboxuser:x:1000:1000:vboxuser:/home/vboxuser:**/bin/bash** -> this is bash shell
